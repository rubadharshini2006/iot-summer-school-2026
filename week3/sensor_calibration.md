# Sensor Calibration

## What is sensor calibration?
Sensor calibration is the process of adjusting a sensor so that its readings match the actual values. It improves the accuracy and reliability of sensor data in IoT systems.

## Why is it important?
- Improves accuracy
- Reduces sensor errors
- Provides reliable IoT data

## Two-Point Calibration Method
1. Measure the sensor value in dry soil (Dry Value).
2. Measure the sensor value in wet soil (Wet Value).
3. Map the readings between the dry and wet values to calculate the soil moisture percentage (0–100%).

Example:
- Dry value = 850
- Wet value = 300
- Readings between them are converted to moisture percentage.
