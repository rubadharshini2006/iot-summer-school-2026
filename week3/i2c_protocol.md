# I2C Protocol

## What is I2C?
I2C (Inter-Integrated Circuit) is a serial communication protocol used to connect multiple sensors and devices to a microcontroller using only two wires.

## SDA and SCL
- SDA (Serial Data): Transfers data between devices.
- SCL (Serial Clock): Provides the clock signal for synchronization.

## I2C Addressing
Each I2C device has a unique address. The master device communicates with a specific slave device using its address.

## Common I2C IoT Sensors
- BMP280 (Temperature and Pressure Sensor)
- MPU6050 (Accelerometer and Gyroscope)
- BH1750 (Light Intensity Sensor)
