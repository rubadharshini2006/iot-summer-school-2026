# LED Blink Project

## Project Title
LED Blink using Arduino UNO

## Hardware Required
- Arduino UNO
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires
- USB Cable

## Circuit Diagram Description
Connect the LED positive (+) terminal to Arduino Pin 13 through a 220Ω resistor.
Connect the LED negative (-) terminal to Arduino GND.

## How to Upload Code

1. Open Arduino IDE.
2. Connect Arduino UNO using USB cable.
3. Select the correct Board and Port.
4. Open the LED Blink program.
5. Click Verify.
6. Click Upload.
7. Observe the LED blinking.

## Expected Output

The LED connected to Pin 13 blinks continuously.
If a potentiometer is connected, the blink speed changes according to the potentiometer position.

## Troubleshooting Tips

1. Check all wire connections.
2. Select the correct COM Port.
3. Ensure the Arduino UNO board is selected in the IDE.
4. Verify the LED polarity.
5. Check that the USB cable is working.
