# Q19 - Difference between analogWrite() and analogRead()

## analogRead()
- Reads the analog voltage from an analog input pin (A0–A5).
- Returns a value between 0 and 1023.
- Example: Reading a temperature sensor or LDR sensor.

## analogWrite()
- Writes a PWM signal to PWM pins (3, 5, 6, 9, 10, 11).
- Accepts values from 0 to 255.
- Example: Controlling LED brightness or motor speed.

## What is PWM?
PWM (Pulse Width Modulation) is a technique used to simulate analog output by rapidly switching a digital signal ON and OFF.

## Why is PWM used?
PWM is used to control the brightness of LEDs, motor speed, and fan speed.

## Practical IoT Examples
- analogRead(): Reading data from a soil moisture sensor in a smart irrigation system.
- analogWrite(): Adjusting LED brightness in a smart street lighting system.
