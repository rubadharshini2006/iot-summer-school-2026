# Theory Answers
# Q9. Difference between git pull, git fetch and git clone

## Git Clone
- Copies a remote repository to the local computer for the first time.
- Downloads all files and commit history.

## Git Fetch
- Downloads the latest changes from the remote repository.
- Does not merge the changes into the local branch.

## Git Pull
- Downloads the latest changes and automatically merges them into the current branch.
- It is equivalent to git fetch + git merge.

# Q10. What is a .gitignore file?

A `.gitignore` file tells Git to ignore files and folders that should not be tracked or uploaded to the repository.

## Arduino .gitignore

```gitignore
*.hex
*.elf

build/

.vscode/

.DS_Store
Thumbs.db
```
