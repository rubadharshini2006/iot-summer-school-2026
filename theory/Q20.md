# Q20 - setup() and loop() in Arduino

## setup()
- The setup() function runs only once when the Arduino is powered on or reset.
- It is used to initialize pins, sensors, and Serial communication.

## loop()
- The loop() function runs continuously after setup().
- It contains the main program logic.

## Effect of long delay()
- A long delay() stops the Arduino from performing other tasks.
- Sensor readings become slow, and the system responds slowly to changes.

## Non-blocking Alternative
- The millis() function is used instead of delay().
- It allows multiple tasks to run without stopping the program, improving responsiveness.
